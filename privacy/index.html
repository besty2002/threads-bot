개인정보처리방침

시행일: 2026년 10월 4일

"스레드봇"(이하 "앱")은 운영자 본인의 Threads 계정 운영을 돕기 위한 개인용 도구입니다. 앱은 Meta의 공식 Threads API만 사용합니다.

1. 수집하는 정보

  • 사용자가 권한을 부여한 Threads 계정의 ID와 사용자 이름
  • 앱으로 게시한 게시물과 그 인사이트 지표(조회수, 좋아요, 답글, 리포스트, 인용, 공유 등)와 계정 팔로워 수
  • 운영자 게시물에 달린 답글의 텍스트와 작성자 사용자 이름(분석 목적)
  • Threads API 액세스 토큰(암호화 저장)

2. 이용 목적

게시물 작성·게시, 성과 분석, 답글 관리에만 사용하며, 광고나 제3자 판매에 사용하지 않습니다.

3. 보관과 보호

액세스 토큰은 암호화해 저장하고, 답글 작성자 정보는 90일이 지나면 익명화합니다.

4. 제3자 제공

법령상 요구가 있는 경우를 제외하고 제3자에게 제공하지 않습니다.

5. 삭제 요청

데이터 삭제 안내 페이지의 방법으로 요청할 수 있습니다. Threads의 계정 설정 > 웹사이트 권한에서 앱 연결을 직접 해제할 수도 있습니다.
